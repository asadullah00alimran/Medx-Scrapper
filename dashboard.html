How Medex Scraper Operates

1

Sequential Traversal

The extension visits Medex brand pages one by one (starting from ID 1, then ID 2, ID 3... up to your chosen End ID).

2

Automatic Data Extraction

When an ID is valid, it extracts Brand Name, Dosage Form, Generic Name, Strength, Manufacturer, Pricing, Indications, Pharmacology, Side Effects, and saves it into IndexedDB.

3

Skipping Missing IDs

If an ID does not exist (404, empty, or redirected to search/home), it gets recorded into the Skipped CSV with the reason.

4

Cloudflare / Security Handling

If Medex presents a captcha challenge, the scraper immediately pauses and alerts you. Simply solve the captcha in the open Medex tab and click Resume.

Generated CSV Files:

  • medex_medicines_[date].csv: Contains 25+ detailed columns with complete product information, indications, dosages, and prices formatted in UTF-8 with BOM (compatible with Microsoft Excel, Google Sheets, LibreOffice, and MySQL/Postgres).
  • medex_skipped_ids_[date].csv: Contains every ID that was skipped, along with the URL and error reason.
